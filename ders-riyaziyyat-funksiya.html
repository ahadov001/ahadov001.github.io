Funksiyalar

Xətti, kvadratik funksiya, qrafiklər, çevrilmələr

Funksiya nədir?

Funksiya «maşın»dır: içinə bir ədəd verirsən, qarşılığında bir ədəd alırsan. y = f(x) — x daxiledilən, y nəticədir.

f(x) = 2x + 1 maşını:
x = 0 → f(0) = 1 · x = 3 → f(3) = 7 · x = −2 → f(−2) = −3
Əsas şərt: bir x-ə yalnız bir y uyğun gəlməlidir. Bir düyməni basanda maşın hər dəfə fərqli nəticə verirsə, o funksiya deyil.

Təyin və qiymətlər oblastı

Təyin oblastı (D) — x-in ala biləcəyi qiymətlər. Qiymətlər oblastı (E) — y-in aldığı qiymətlər.

  • Kəsrdə məxrəc ≠ 0 → y = 1/(x−2) üçün x ≠ 2
  • Kök altı ≥ 0 → y = √(x−3) üçün x ≥ 3
  • Loqarifmin altı > 0 → y = log(x) üçün x > 0

Parabolanın zirvəsi

y = ax² + bx + c üçün zirvənin absisi: x₀ = −b / 2a. Ordinatı isə y₀ = f(x₀).

y = x² − 4x + 3 → x₀ = 4/2 = 2 → y₀ = 4 − 8 + 3 = −1. Zirvə (2; −1). a > 0 olduğundan bu minimum nöqtədir.
«Maksimum/minimum qiyməti tap» tipli məsələlər məhz bu düsturla həll olunur — sahəni ən böyük edən ölçülər, mənfəəti maksimum edən qiymət və s.

Cüt və tək funksiyalar

  • Cüt: f(−x) = f(x) — qrafik Oy oxuna simmetrik (y = x²)
  • Tək: f(−x) = −f(x) — qrafik başlanğıca simmetrik (y = x³)

Artan və azalan

x böyüdükcə y də böyüyürsə funksiya artandır, kiçilirsə azalandır. y = 2x + 1 artandır (k > 0), y = −2x + 1 azalandır (k < 0).
