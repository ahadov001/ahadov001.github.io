Təlim metodları, təşkil formaları və dərs tipləri

İzahlı-illüstrativ, problemli, tədqiqat, layihə metodları; frontal, qrup, cüt, fərdi iş; dərs tipləri

Təlim metodları

MetodMahiyyətiŞagirdin rolu
İzahlı-illüstrativMüəllim hazır bilik verir, nümunə göstərir.Qəbul edən
ReproduktivVerilmiş nümunə üzrə təkrarlayıcı məşq.İcraçı
Problemli təlimProblem vəziyyəti yaradılır, şagird həlli axtarır.Axtaran
Qismən-axtarış (evristik)Müəllim sualla istiqamət verir, şagird addım-addım tapır.Yönləndirilən kəşfçi
TədqiqatŞagird fərziyyə irəli sürür, yoxlayır, nəticə çıxarır.Müstəqil tədqiqatçı
LayihəUzunmüddətli iş, real məhsulla bitir.Planlayan və yaradan

Kurikulum yanaşmasında ağırlıq problemli, tədqiqat və layihə kimi şagirdin fəal olduğu metodlara verilir; izahlı metod isə yardımçıdır.

Təşkil formaları

  • Frontal — bütün sinif eyni vaxtda eyni işi görür.
  • Fərdi — hər kəs müstəqil işləyir.
  • Cüt — iki şagird əməkdaşlıq edir.
  • Qrup — 3–5 nəfərlik komandalar; rollar bölünür (idarəçi, katib, təqdimatçı, vaxt nəzarətçisi).
Qrup işi nə vaxt işləmir? Rollar bölünməyəndə, tapşırıq hamının iştirakını tələb etməyəndə, vaxt və meyar verilməyəndə «bir nəfər işləyir, qalanları baxır» halı yaranır.

TipƏsas məqsəd

Test məntiqi: «şagird özü tapır, müəllim yönəldir» → problemli/evristik/tədqiqat; «müəllim hazır verir» → izahlı-illüstrativ.

Özünü yoxla

Sualı aç, cavabı düşün, sonra doğru cavaba bax.

Sual 1. Şagird fərziyyə irəli sürür, yoxlayır və nəticə çıxarır. Bu hansı metoddur?
  1. İzahlı-illüstrativ
  2. Reproduktiv
  3. Tədqiqat
  4. Frontal

Cavab: C. Fərziyyə, yoxlama və nəticə tədqiqat metodunun mərhələləridir.

Sual 2. «Frontal» nə deməkdir?
  1. Hər şagird ayrıca işləyir
  2. Bütün sinif eyni vaxtda eyni işi görür
  3. Şagirdlər qruplara bölünür
  4. Ev tapşırığı

Cavab: B. Frontal formada sinif bütövlükdə eyni fəaliyyətdə iştirak edir.

Sual 3. Bölmə sonunda biliyin sistemləşdirilməsi hansı dərs tipinə aiddir?
  1. Yeni biliyin verilməsi
  2. Təkrar-ümumiləşdirmə
  3. Yoxlama
  4. Yalnız ev tapşırığı

Cavab: B. Təkrar-ümumiləşdirmə dərsi öyrənilənləri bütövləşdirir.
