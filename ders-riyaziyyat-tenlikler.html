6-ci mövzu · izah pulsuzdur

Tənliklər

Xətti və kvadrat tənliklər, tənliklər sistemi

Tənlik nədir?

Naməlumu olan bərabərlik. Tənliyi həll etmək — bərabərliyi doğru edən dəyişənin qiymətini tapmaqdır. Buna kök deyilir.

x + 5 = 12 → x = 7. Yoxlayırıq: 7 + 5 = 12 ✓
Həmişə yoxla — 10 saniyə sərf edib səhvdən qurtulursan.

Xətti tənlik: ax + b = 0

Bir addımlı qayda: naməlumları bir tərəfə, ədədləri digər tərəfə topla.

3x − 7 = 2x + 5
3x − 2x = 5 + 7
x = 12
Qayda: bərabərliyin bir tərəfindən digərinə keçən həd işarəsini dəyişir. Tərəzinin iki gözü kimidir — birindən götürdüyünü digərinə əlavə etmək lazımdır.

Kvadrat tənlik: ax² + bx + c = 0

Diskriminant düsturu hər halda işləyir:

D = b² − 4ac
D > 0 → iki kök: x = (−b ± √D) / 2a
D = 0 → bir kök: x = −b / 2a
D < 0 → həqiqi kök yoxdur

Nümunə: x² − 5x + 6 = 0 → D = 25 − 24 = 1 → x = (5 ± 1)/2 → x₁ = 3, x₂ = 2.

Viyet teoremi — vaxt qazandıran yol

x² + px + q = 0 tənliyi üçün: x₁ + x₂ = −p, x₁ · x₂ = q.

x² − 5x + 6 = 0 üçün: cəmi 5, hasili 6 olan iki ədəd → 2 və 3. Diskriminant hesablamadan cavab hazırdır! Əmsallar kiçik tam ədədlərdirsə həmişə bunu sına.

Tənliklər sistemi

İki üsul var:

  • Əvəzetmə: birindən bir dəyişəni ifadə edib digərinə yaz
  • Toplama: tənlikləri topla/çıx ki, bir dəyişən yox olsun
x + y = 10 və x − y = 4
Toplayırıq: 2x = 14 → x = 7 → y = 3

Mətn məsələləri — addım-addım

  1. Nəyi tapmaq lazımdır? Onu x qoy.
  2. Qalan kəmiyyətləri x ilə ifadə et.
  3. Şərtdən tənlik qur.
  4. Həll et və sualın nə soruşduğunu yenidən oxu — tez-tez x deyil, 2x+5 soruşulur.
