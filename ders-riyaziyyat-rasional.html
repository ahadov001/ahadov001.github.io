Tam və rasional ədədlər

Mənfi ədədlər, modul, dərəcə, kök

Ədəd çoxluqları — iç-içə qutular

Riyaziyyatda ədədlər bir-birini əhatə edən çoxluqlara bölünür:

İşarəAdNümunə

Fərqi belə yadda saxla: rasional ədədi kəsr şəklində yazmaq olar (a/b). İrrasional ədədi yazmaq olmur — onluq yazılışı sonsuz və dövrsüzdür. π = 3,14159… heç vaxt təkrarlanmır.

Mənfi ədədlərlə əməllər

  • Toplama: işarələr eynidirsə topla, işarəni saxla: −3 + (−5) = −8
  • İşarələr fərqlidirsə çıx, böyük modulun işarəsini qoy: −7 + 3 = −4
  • Vurma/bölmə: eyni işarə → müsbət, fərqli işarə → mənfi
(−2)·(−3) = 6 · (−2)·3 = −6 · (−12):(−4) = 3
«Düşmənimin düşməni dostumdur» — mənfi vurulsun mənfi müsbət verir. Belə yadda saxlamaq asandır.

Modul (mütləq qiymət)

|a| ədədin sıfırdan məsafəsidir, həmişə mənfi olmayan: |5| = 5, |−5| = 5, |0| = 0.

|x| = 3 tənliyinin iki həlli var: x = 3 və x = −3. Çünki hər ikisi sıfırdan 3 vahid aralıdır. Modul tənliklərində həmişə iki variant yoxlamaq lazımdır.

Dərəcə qanunları

aᵐ · aⁿ = am+n2³ · 2² = 2⁵ = 32
aᵐ : aⁿ = am−n2⁵ : 2² = 2³ = 8
(aᵐ)ⁿ = amn(2³)² = 2⁶ = 64
a⁰ = 15⁰ = 1 (a ≠ 0)
a−n = 1/aⁿ2⁻³ = 1/8
Mənfi dərəcə «tərs çevir» deməkdir, mənfi nəticə demək deyil! 2⁻³ = 1/8 müsbətdir.

Kvadrat kök

√a — kvadratı a verən mənfi olmayan ədəd. √16 = 4 (−4 deyil, çünki kök işarəsi yalnız müsbət qiymət verir).

  • √(ab) = √a · √b → √50 = √25·√2 = 5√2
  • √(a/b) = √a / √b
  • √a² = |a| — modul işarəsi vacibdir!
