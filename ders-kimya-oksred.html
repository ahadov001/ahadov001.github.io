Oksidləşmə-reduksiya

Oksidləşmə dərəcəsi, elektron balansı

Oksidləşmə və reduksiya

Yadda saxlamağın asan yolu:
Oksidləşmə — elektron verir, oksidləşmə dərəcəsi artır
Reduksiya — elektron alır, dərəcə azalır
İkisi həmişə birlikdə gedir — kimsə verməsə, kimsə ala bilməz.

Kim kimdir?

OksidləşdiriciElektron alırÖzü reduksiya olunur
ReduksiyaediciElektron verirÖzü oksidləşir
Zn + CuSO₄ → ZnSO₄ + Cu
Zn⁰ → Zn²⁺ (2e verir) → oksidləşir, reduksiyaedicidir
Cu²⁺ → Cu⁰ (2e alır) → reduksiya olunur, oksidləşdiricidir

Oksidləşmə dərəcəsini tapmaq

  • Sadə maddələrdə: 0 (O₂, Fe, H₂)
  • Oksigen: adətən −2 (peroksidlərdə −1)
  • Hidrogen: adətən +1 (metal hidridlərində −1)
  • Molekulda cəm sıfırdır, ionda ionun yükünə bərabərdir
H₂SO₄-də kükürd: 2(+1) + x + 4(−2) = 0 → x = +6
KMnO₄-də manqan: (+1) + x + 4(−2) = 0 → x = +7

Metalların fəaliyyət sırası

K, Na, Ca, Mg, Al, Zn, Fe, Ni, Sn, Pb, (H), Cu, Hg, Ag, Pt, Au

Praktik nəticələr:
• Hidrogendən əvvəl olanlar turşudan H₂ çıxarır (Zn + HCl ✓)
• Hidrogendən sonra olanlar çıxarmır (Cu + HCl ✗)
• Daha aktiv metal az aktivi duz məhlulundan sıxışdırır (Fe + CuSO₄ ✓)

Korroziya

Metalın ətraf mühitin təsirindən oksidləşərək dağılması. Dünya iqtisadiyyatına hər il milyardlarla zərər verir.

Mübarizə üsulları: rəngləmə, sinkləmə (qalvanlaşdırma), legirləmə (paslanmayan polad), protektor metal əlavəsi.

Sinkləmə niyə işləyir? Sink dəmirdən aktivdir — «özünü qurban verir», əvvəlcə o oksidləşir, dəmir qorunur. Hətta örtük cızılsa da müdafiə davam edir.

Elektroliz

Elektrik cərəyanı ilə məcburi oksidləşmə-reduksiya.

  • Katodda (−): reduksiya, metal ayrılır
  • Anodda (+): oksidləşmə

Sənayedə: alüminium istehsalı, metalların təmizlənməsi, xrom-nikel örtük çəkilməsi, xlor və qələvi alınması.

Qalvanik element

Kortəbii oksidləşmə-reduksiyadan elektrik enerjisi almaq. Bütün batareyalar və akkumulyatorlar bu prinsiplə işləyir — telefonundaki litium-ion batareya da daxil.
