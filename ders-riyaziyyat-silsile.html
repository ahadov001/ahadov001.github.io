Ardıcıllıqlar və silsilələr

Ədədi və həndəsi silsilə, düsturlar

Ardıcıllıq nədir?

Müəyyən qaydaya tabe olan ədədlər sırası: a₁, a₂, a₃, … Hər üzvün öz nömrəsi var.

2, 4, 6, 8, … → aₙ = 2n
1, 4, 9, 16, … → aₙ = n²

Arifmetik silsilə — bərabər fərq

Hər üzv əvvəlkindən sabit d qədər fərqlənir.

n-ci üzvaₙ = a₁ + (n−1)d
n üzvün cəmiSₙ = n(a₁ + aₙ)/2
Orta xassəaₙ = (aₙ₋₁ + aₙ₊₁)/2
3, 7, 11, 15, … → a₁ = 3, d = 4
a₁₀ = 3 + 9·4 = 39
S₁₀ = 10(3 + 39)/2 = 210
Cəm düsturunu yadda saxlamağın yolu: birinci və sonuncunu topla, üzv sayının yarısına vur. Kiçik Qauss 1-dən 100-ə qədər cəmi belə tapıb: (1+100)·50 = 5050.

Həndəsi silsilə — bərabər nisbət

Hər üzv əvvəlkinin sabit q qatıdır.

n-ci üzvbₙ = b₁ · qn−1
n üzvün cəmiSₙ = b₁(qⁿ − 1)/(q − 1)
Sonsuz cəm (|q| < 1)S = b₁/(1 − q)
2, 6, 18, 54, … → b₁ = 2, q = 3
b₅ = 2 · 3⁴ = 162
S₄ = 2(81−1)/(3−1) = 80

Həndəsi silsilənin gücü

Şahmat taxtası əfsanəsi: birinci xanaya 1 buğda, sonrakına iki qat. 64-cü xanada 2⁶³ dənə olur — dünyanın bütün buğdasından çox. Həndəsi artım insanın gözlədiyindən qat-qat sürətlidir. Bank faizi, əhali artımı, virus yayılması — hamısı belə işləyir.

Sonsuz azalan silsilə

|q| < 1 olanda üzvlər sıfıra yaxınlaşır və sonsuz cəm sonlu ədəd verir.

1 + 1/2 + 1/4 + 1/8 + … = 1/(1 − 1/2) = 2
Sonsuz sayda ədəd topladın, cəm cəmi 2 oldu. Qədim yunanları çaşdıran paradoks budur.
