Verilənlər bazası

Cədvəl, sorğu, açar, SQL əsasları

Verilənlər bazası nədir?

Nizamlı saxlanan, asanlıqla axtarıla və dəyişdirilə bilən verilənlər toplusu.

Niyə Excel kifayət etmir? 100 sətir üçün Excel yaxşıdır. Milyon sətir, onlarla istifadəçinin eyni vaxtda işləməsi, məlumat bütövlüyünün qorunması lazımdırsa — verilənlər bazası lazımdır. Bank, mağaza, məktəb sistemləri hamısı VB üzərində işləyir.

Relyasion model

Verilənlər cədvəllərdə saxlanır. Cədvəl sətir və sütunlardan ibarətdir.

Əsas açar nə üçün vacibdir? İki tələbənin adı «Əli Məmmədov» ola bilər — onları ayırd etmək üçün unikal ID lazımdır. Açar təkrarlanmır və boş qalmır.

Cədvəllər arasında əlaqə

Tələbələr cədvəli: ID, Ad, Qrup_ID
Qruplar cədvəli: Qrup_ID, Qrup_adı, Fakültə
Qrup adını hər tələbə sətrində təkrarlamaq yerinə bir dəfə Qruplar cədvəlində saxlayırsan və ID ilə istinad edirsən. Bu, normallaşdırmadır — təkrarı aradan qaldırır.

Sorğu nümunələri

SELECT * FROM telebeler;
Bütün tələbələri göstər.

SELECT ad, bal FROM telebeler WHERE bal > 80;
Balı 80-dən çox olanların ad və balını göstər.

SELECT ad FROM telebeler ORDER BY bal DESC;
Bala görə azalan sırada sırala.

SELECT qrup, COUNT(*) FROM telebeler GROUP BY qrup;
Hər qrupda nə qədər tələbə var?

Əsas bəndlər

  • WHERE — şərt qoyur
  • ORDER BY — sıralayır (ASC artan, DESC azalan)
  • GROUP BY — qruplaşdırır
  • JOIN — cədvəlləri birləşdirir
  • LIMIT — nəticə sayını məhdudlaşdırır

İndeks və performans

İndeks kitabın əlifba göstəricisi kimidir. Onsuz baza hər sətri bir-bir yoxlayır (milyon sətirdə yavaş). İndekslə birbaşa lazımi yerə gedir. Çox işlənən axtarış sahələrinə indeks qoyulur — lakin hər indeks yaddaş tutur və yazma əməliyyatını bir az yavaşıdır. Balans lazımdır.

Təhlükəsizlik və bütövlük

  • Tranzaksiya — ya hamısı icra olunur, ya heç biri (bank köçürməsində kritikdir)
  • Yedəkləmə — mütləq və mütəmadi
  • İcazələr — hər istifadəçi yalnız öz işinə lazım olanı görür
