5-ci mövzu · izah pulsuzdur

Cəbri ifadələr

Eynilik çevrilmələri, vuruqlara ayırma, qısa vurma düsturları

Cəbri ifadə nədir?

Hərflərlə yazılmış riyazi yazılış: 3x + 2y − 5. Hərflər dəyişən, ədədlər əmsal adlanır. Cəbr «ədədləri hərflə əvəz edib ümumi qayda tapmaq» sənətidir.

«Hər alma 2 manatdır» → n alma n·2 manat. Burada 2n cəbri ifadədir — bir düsturla bütün halları əhatə edir.

Oxşar hədləri toplamaq

Yalnız eyni hərf və eyni dərəcəli hədləri toplamaq olar:

3x + 5x = 8x ✓
3x + 5x² — toplanmır, fərqli dərəcədir ✗
3x + 5y — toplanmır, fərqli hərfdir ✗
Alma ilə armudu toplamırsan. 3 alma + 5 alma = 8 alma, amma 3 alma + 5 armud = 3 alma və 5 armud olaraq qalır.

Müxtəsər vurma düsturları — ən çox işlənən beşlik

(a+b)² = a² + 2ab + b²(x+3)² = x² + 6x + 9
(a−b)² = a² − 2ab + b²(x−3)² = x² − 6x + 9
a² − b² = (a−b)(a+b)x² − 9 = (x−3)(x+3)
(a+b)³ = a³ + 3a²b + 3ab² + b³
a³ ± b³ = (a±b)(a² ∓ ab + b²)
Ən çox səhv: (a+b)² ≠ a² + b². Ortadaki 2ab itmir! Yoxla: (2+3)² = 25, amma 4 + 9 = 13. Bərabər deyil.

Vuruqlara ayırma — 4 üsul

  • Ümumi vuruğu çıxarmaq: 6x² + 9x = 3x(2x + 3)
  • Düsturla: x² − 16 = (x−4)(x+4)
  • Qruplaşdırma: x³ + x² + x + 1 = x²(x+1) + (x+1) = (x+1)(x²+1)
  • Kvadrat üçhədli: x² + 5x + 6 = (x+2)(x+3) — cəmi 5, hasili 6 olan iki ədəd tap

Kəsr-rasional ifadələri sadələşdirmək

Surət və məxrəci vuruqlara ayırıb ortaq vuruğu ixtisar edirsən:

(x² − 9)/(x + 3) = (x−3)(x+3)/(x+3) = x − 3
Şərt: x ≠ −3, çünki məxrəc sıfır ola bilməz. Bu şərti yazmağı unutma — imtahanda bal aparır.
