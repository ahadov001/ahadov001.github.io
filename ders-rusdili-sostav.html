Окончание və суффикс fərqi vacibdir:
Суффикс yeni söz yaradır: дом → домик (fərqli söz)
Окончание formanı dəyişir: дом → дома (eyni söz, fərqli hal)
Sonluğu tapmaq üçün sözü dəyişdir — dəyişən hissə sonluqdur.

Однокоренные слова

Eyni kökdən olan və mənaca bağlı sözlər: лес, лесник, лесной, перелесок.

Diqqət tələsi: вода və водитель eyni kökdən deyil! Birincisi «вод» (su), ikincisi «вод» (вести — aparmaq). Yazılış eynidir, məna fərqlidir — kök təsadüfi üst-üstə düşür. Həmişə mənanı yoxla.

Söz yaradıcılığı üsulları

  • Приставочный — бежать → побежать
  • Суффиксальный — учить → учитель
  • Приставочно-суффиксальный — школа → пришкольный
  • Бессуффиксный — бегать → бег
  • Сложение — пар + воз → паровоз
  • Аббревиация — ВУЗ, МГУ

Mürəkkəb sözlər

Birləşdirici saitlər: о və е.

паровоз, путешествие, землетрясение
Qayda: bərk samitdən sonra о, yumşaq samit, ж, ш, ц-dən sonra е.

Kökdə səs növbələşməsi

к // чрука — ручка
г // жнога — ножка
х // шмуха — мушка
д // жводить — вожу
о // арасти — рост
Növbələşmə kökü «tanınmaz» edə bilər, lakin söz eyni kökdəndir. Bunu bilmək yoxlama sözü tapmağa kömək edir.

Nulevoye okonchanie

Sonluq görünmür, lakin qrammatik məna daşıyır: дом□ (kişi cinsi, tək, именительный hal). Sözü dəyişdirsən sonluq görünür: дома, дому.

Morfem təhlili

Alqoritm:
1. Sözü dəyişdirib sonluğu tap
2. Eyni kökdən sözlər taparaq kökü müəyyən et
3. Kökdən əvvəl qalan — prefiks
4. Kök və sonluq arasında qalan — şəkilçi
