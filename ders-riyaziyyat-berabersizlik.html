Bərabərsizliklər

Xətti və kvadrat bərabərsizliklər, intervallar üsulu

Bərabərsizlik nədir?

Bərabərlik yerinə <, >, ≤, ≥ işarələri olan yazılış. Cavab bir ədəd deyil, ədədlər aralığı olur.

x + 3 > 7 → x > 4. Yəni 4,1 də, 5 də, 100 də cavabdır. Cavabı interval kimi yazırıq: x ∈ (4; +∞).

Ən vacib qayda

Mənfi ədədə vurduqda və ya böldükdə bərabərsizlik işarəsi çevrilir!
−2x > 6 → x < −3 (işarə dəyişdi)
Niyə? 2 < 3 doğrudur. (−1)-ə vuraq: −2 və −3. Amma −2 > −3! İşarə çevrilməlidir.

Kvadrat bərabərsizliklər — intervallar üsulu

  1. Sıfıra bərabərləşdirib kökləri tap
  2. Kökləri ədəd oxunda qeyd et
  3. Hər intervalda işarəni yoxla
  4. Lazım olan işarəli intervalları seç
x² − 5x + 6 > 0
Köklər: 2 və 3. Ox üç hissəyə bölünür.
x < 2 → müsbət ✓ · 2 < x < 3 → mənfi ✗ · x > 3 → müsbət ✓
Cavab: x ∈ (−∞; 2) ∪ (3; +∞)
Parabola üsulu: a > 0 olanda parabolanın qolları yuxarıdır — köklərdən kənarda müsbət, arasında mənfidir. Bir cizgi çəkib dərhal görürsən.

Kəsr bərabərsizliklər

Məxrəci heç vaxt sıfıra bərabər ola bilməz, ona görə o nöqtə həmişə çıxarılır.

(x−1)/(x+2) ≥ 0 → kritik nöqtələr: 1 və −2.
Cavab: x ∈ (−∞; −2) ∪ [1; +∞). Diqqət: −2 dairəvi mötərizədədir, 1 kvadrat.
