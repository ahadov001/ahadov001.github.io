Şəbəkə və internet

IP, protokol, veb, axtarış sistemləri

Şəbəkə nədir?

Məlumat mübadiləsi üçün birləşdirilmiş qurğular toplusu.

LANLokal — ofis, məktəb, ev
WANGeniş — şəhərlər, ölkələr arası
İnternetŞəbəkələrin qlobal şəbəkəsi

IP ünvan və DNS

Hər qurğunun şəbəkədə unikal IP ünvanı var (192.168.1.1 kimi). İnsanlar rəqəmləri yadda saxlamadığı üçün domen adları işlənir.

DNS internetin telefon kitabıdır: «google.com» yazırsan, DNS onu IP ünvana çevirir. Bu proses saniyənin kiçik hissəsində baş verir və sən heç fərqinə varmırsan.

Protokollar

  • HTTP/HTTPS — veb səhifələr
  • TCP/IP — internetin əsas protokol dəsti
  • SMTP / IMAP / POP3 — e-poçt
  • FTP — fayl ötürmə
  • DNS — ad çevirmə
HTTPS-dəki «S» — Secure. Məlumat şifrələnir. Ünvan sətrindəki kilid nişanı buna işarədir. Bank, e-poçt və ya hər hansı parol daxil etdiyin saytda mütləq HTTPS olmalıdır. HTTP-də məlumat açıq mətnlə gedir və ələ keçirilə bilər.

Şəbəkə qurğuları

  • Router — şəbəkələr arasında paketləri yönləndirir
  • Switch (kommutator) — şəbəkə daxilində paylayır
  • Modem — siqnalı çevirir
  • Access point — simsiz giriş nöqtəsi

Paketlərlə ötürmə

İnternet məlumatı bütöv göndərmir — kiçik paketlərə bölür. Hər paket müstəqil yolla gedə bilər və sonda yenidən birləşdirilir. Buna görə internet dayanıqlıdır: bir xətt kəsilsə, paketlər başqa yolla gedir. Bu dizayn soyuq müharibə dövründə məhz dayanıqlılıq üçün düşünülüb.

Veb necə işləyir?

  1. Brauzerə ünvan yazırsan
  2. DNS domeni IP-yə çevirir
  3. Brauzer serverə HTTP sorğusu göndərir
  4. Server HTML, CSS, JS fayllarını qaytarır
  5. Brauzer onları «oxuyub» səhifəni çəkir
HTMLStruktur — skelet
CSSGörünüş — paltar
JavaScriptDavranış — hərəkət

Bulud xidmətləri

Fayl saxlama (Drive, Dropbox), hesablama gücü (AWS, Azure), proqram xidməti (Google Docs, onlayn redaktorlar). Üstünlük: hər yerdən giriş, avtomatik yedəkləmə. Çatışmazlıq: internetdən asılılıq, məxfilik sualları.

Axtarış bacarığı

Effektiv axtarış üsulları:
• Dəqiq ifadə: "maşın öyrənməsi" dırnaqda
• Sayt daxilində: site:edu.az qəbul
• Söz çıxarmaq: python -ilan
• Fayl tipi: filetype:pdf dərslik
Bu üsullar vaxtı dəfələrlə qısaldır.
