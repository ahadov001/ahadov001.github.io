MƏRHƏLƏ 2 — SUPABASE  (20 dəqiqə)  ← hesab və balans burada yaşayır
───────────────────────────────────────────────────────────────────
  Supabase pulsuz, kart tələb etmir. Pulsuz tarif: 500 MB baza,
  ayda 50 000 istifadəçi. Sizin ölçüdə bu uzun müddət bəs edir.

  2.1. supabase.com → Start your project → e-poçtla qeydiyyat
  2.2. "New project" → ad: sinaq → region: Frankfurt (ən yaxını)
       → güclü database parolu yazın və saxlayın
  2.3. Proyekt hazır olana qədər ~2 dəqiqə gözləyin

  2.4. Sol menyuda SQL Editor → "New query"
       supabase/01-sxem.sql faylını açıb MƏTNİ BÜTÖV kopyalayın,
       pəncərəyə yapışdırın → RUN
       "Success" yazısı görünməlidir.

  2.5. Yenə SQL Editor → New query
       supabase/02-qiymetler.sql faylını eyni şəkildə RUN edin
       (174 xidmətin qiymətini bazaya yazır)

  2.6. Sol menyuda Project Settings → API
       İki dəyəri kopyalayın:
         • Project URL          (https://xxxx.supabase.co)
         • anon public açarı    (uzun mətn)

  2.7. assets/config.js faylını açıb o iki dəyəri yazın:

         window.SB_CONFIG = {
           url: "https://xxxx.supabase.co",
           anonKey: "eyJhbGci..."
         };

       Faylı GitHub-a yenidən yükləyin.

       ⚠ "service_role" açarını BURAYA YAZMAYIN. O açar yalnız
         3-cü mərhələdə, serverdə istifadə olunur.
         anon açarının saytda görünməsi normaldır — bazadaki
         təhlükəsizlik qaydaları (RLS) hər şeyi qoruyur.

  2.8. Authentication → Sign In / Providers → Email
       "Confirm email" seçimini SÖNDÜRÜN (tələbələr e-poçt
       təsdiqi gözləmədən dərhal başlasın). Sonra istəsəniz
       yenidən yandıra bilərsiniz.

  BU MƏRHƏLƏDƏN SONRA: qeydiyyat, giriş, şəxsi kabinet,
  irəliləyiş, transkript — hamısı işləyir. Balans 0 olduğu üçün
  testlər hələ alınmır. Özünüzə balans yazmaq üçün SQL Editor:

      select public.balans_artir(
        (select id from auth.users where email = 'sizin@mail.com'),
        10000);          -- 100 AZN

  Bununla bütün saytı özünüz yoxlaya bilərsiniz.

MƏRHƏLƏ 3 — ÖDƏNİŞ  (30 dəqiqə)  ← yalnız 4 məhsul!
───────────────────────────────────────────────────────────────────
  Köhnə planda 174 məhsul yaratmaq lazım idi. Balans sistemi ilə
  CƏMİ 4 MƏHSUL kifayətdir — qalan hər şey sayt daxilində balansdan
  gedir.

  3.1. Lemon Squeezy → 4 məhsul yaradın:
         "5 AZN balans"   · "10 AZN balans"
         "25 AZN balans"  · "50 AZN balans"
       Qiymətləri Lemon Squeezy-nin valyutasında uyğun qoyun.

  3.2. Hər məhsulun VARIANT ID-sini tapın:
       məhsulu açın → Variants bölməsi → ID rəqəmi
       (yaxud məhsulun linkində /buy/xxxx hissəsindən sonra
        Lemon Squeezy API-də görünür)

  3.3. supabase/functions/balans-webhook/index.ts faylını açın,
       PAKETLER siyahısını öz variant ID-lərinizlə doldurun:

         const PAKETLER = {
           "123456": 500,    // 5 AZN
           "123457": 1000,   // 10 AZN
           "123458": 2500,   // 25 AZN
           "123459": 5000,   // 50 AZN
         };

       ⚠ Məbləğ niyə burada? Çünki istifadəçinin linkindən
         gələn rəqəmə etibar etmək olmaz — adam 5 AZN ödəyib
         linkdə 5000 yazardı. Variant ID Lemon Squeezy-nin
         özündən gəlir, saxtalaşdırıla bilmir.

  3.4. Supabase → Edge Functions → "Deploy a new function"
       Ad: balans-webhook
       index.ts faylının məzmununu yapışdırın → Deploy

  3.5. Supabase → Edge Functions → Secrets bölməsində 3 dəyər:
         SB_URL                = Project URL
         SB_SERVICE_KEY        = service_role açarı (Settings → API)
         LEMON_WEBHOOK_SECRET  = özünüz uzun təsadüfi mətn yazın
                                 (məs. 32 simvol) və saxlayın

  3.6. Lemon Squeezy → Settings → Webhooks → "+"
         URL:     https://xxxx.supabase.co/functions/v1/balans-webhook
         Secret:  3.5-də yazdığınız LEMON_WEBHOOK_SECRET
         Events:  order_created  (yalnız bunu seçin)

  3.7. 4 məhsulun "Share / Buy link" linklərini
       assets/balans-paketleri.js faylına yazın və GitHub-a
       yenidən yükləyin.

  3.8. YOXLAMA — Lemon Squeezy-də Test mode açın, kart:
         4242 4242 4242 4242 · istənilən tarix · CVC 123
       Ödənişdən sonra kabinetdə balans artmalıdır.
       Artmadısa: Supabase → Edge Functions → balans-webhook →
       Logs bölməsinə baxın, səbəb orada yazılır.

MƏRHƏLƏ 4 — İSTİFADƏ
───────────────────────────────────────────────────────────────────
  QİYMƏTİ DƏYİŞMƏK (Supabase → SQL Editor):
    -- bir mövzu
    update public.qiymetler set qiymet = 300 where acar = 'kimya:rabite';
    -- bütün mövzular 3 AZN
    update public.qiymetler set qiymet = 300 where acar like '%:%';
    -- bütün imtahanlar 5 AZN
    update public.qiymetler set qiymet = 500
      where acar ~ '^(qb|bx|miq)';
    -- tam paket
    update public.qiymetler set qiymet = 2000 where acar = 'paket';

  KİMƏSƏ HƏDİYYƏ BALANS:

    (lemon_order_id-ni odenisler cədvəlindən tapın)

  SATIŞ HESABATI:
