Dərsin planlaşdırılması və mərhələləri

İllik, mövzu və gündəlik plan; dərsin məqsədi; tədqiqata əsaslanan dərsin mərhələləri

Planlaşdırmanın səviyyələri

  • İllik (uzunmüddətli) plan — fənn üzrə ilin ümumi bölgüsü: bölmələr, saatlar, standartlar.
  • Bölmə/mövzu planı — bir neçə dərsi əhatə edən ardıcıllıq.
  • Gündəlik (dərs) planı — konkret dərsin məqsədi, fəaliyyətləri, resursları, qiymətləndirməsi.

Dərsin məqsədi necə yazılır?

Məqsəd alt standartdan götürülür, müşahidə olunan feillə və şagird adından yazılır.

Düzgün: «Şagird iki fərqli mətnin üslubunu müqayisə edir.»
Yanlış: «Müəllim üslub haqqında məlumat verir.» (müəllimin işi yazılıb, şagirdin nəticəsi yox)

Dərsin mərhələləri (tədqiqat əsaslı model)

  1. Motivasiya və problemin qoyuluşu — maraq oyadılır, problem sualı verilir.
  2. Tədqiqatın aparılması — şagirdlər məlumat toplayır, təcrübə/müşahidə edir.
  3. Məlumat mübadiləsi — nəticələr qrup və ya cüt daxilində bölüşülür.
  4. Məlumatın müzakirəsi və təşkili — məlumat təhlil edilir, sistemləşdirilir.
  5. Nəticə və ümumiləşdirmə — qayda, anlayış, nəticə formalaşdırılır.
  6. Yaradıcı tətbiqetmə — öyrənilən yeni vəziyyətdə istifadə olunur.
  7. Qiymətləndirmə — dərsin nəticəsi meyarlara görə ölçülür.
Ardıcıllığı yadda saxla: motivasiya → tədqiqat → mübadilə → müzakirə → nəticə → tətbiq → qiymətləndirmə. Testdə çox vaxt «hansı mərhələdə hansı iş görülür?» kimi verilir.

Yaxşı planın əlamətləri

  • Məqsəd ölçülə biləndir və qiymətləndirmə məqsədə uyğundur.
  • Fəaliyyətlərin əksəriyyətini şagird yerinə yetirir.
  • Vaxt reallıqla bölünüb, ehtiyat variant düşünülüb.
  • Fərqli səviyyəli şagirdlər üçün tapşırıq variantları var.

Özünü yoxla

Sualı aç, cavabı düşün, sonra doğru cavaba bax.

Sual 1. Aşağıdakı mərhələlərdən hansı tədqiqat əsaslı dərsdə «tədqiqatın aparılması»ndan dərhal sonra gəlir?
  1. Motivasiya
  2. Məlumat mübadiləsi
  3. Yaradıcı tətbiqetmə
  4. Qiymətləndirmə

Cavab: B. Ardıcıllıq: motivasiya → tədqiqat → məlumat mübadiləsi → müzakirə → nəticə → tətbiq → qiymətləndirmə.

Sual 2. Hansı dərs məqsədi düzgün yazılıb?
  1. Mövzunu izah etmək
  2. Şagirdlərə düsturu göstərmək
  3. Şagird düsturu tətbiq edərək məsələ həll edir
  4. Dərsi vaxtında bitirmək

Cavab: C. Məqsəd şagirdin ölçülə bilən fəaliyyəti kimi yazılmalıdır.

Sual 3. Yeni vəziyyətdə öyrənilənin istifadəsi dərsin hansı mərhələsidir?
  1. Motivasiya
  2. Nəticə
  3. Yaradıcı tətbiqetmə
  4. Məlumat mübadiləsi

Cavab: C. Bu, yaradıcı tətbiqetmə mərhələsidir.
