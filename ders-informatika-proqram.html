Proqramlaşdırma əsasları

Dəyişən, şərt, dövr, massiv, funksiya

Proqramlaşdırma dilləri

PythonSadə sintaksis, öyrənmək üçün ideal, data və AI
JavaScriptVeb saytların interaktivliyi
C / C++Sürətli, sistem proqramlaşdırması, oyunlar
JavaKorporativ sistemlər, Android

Hansı dildən başlamaq? Python — sintaksisi ingilis dilinə yaxındır, az kod yazıb çox nəticə alırsan. Əsas olan dil deyil, alqoritmik düşüncədir: onu bir dildə öyrəndinsə, digərinə keçmək asandır.

Kompilyator və interpretator

  • Kompilyator — bütün proqramı əvvəlcə maşın koduna çevirir, sonra işləyir (C++). Sürətli icra.
  • İnterpretator — sətir-sətir icra edir (Python). Yazmaq rahat, icra bir az yavaş.

Python-da sadə proqram:
ad = input("Adınız: ")
print("Salam, " + ad)

Dövr:
for i in range(5):
    print(i)
Bu, 0-dan 4-ə qədər çap edir.

Şərt və dövr

Şərt:
if bal >= 50:
    print("Keçdi")
else:
    print("Kəsildi")

Dövr: for — say məlumdursa, while — şərt ödənənə qədər
Python-da girinti (indent) sintaksisin bir hissəsidir! Digər dillərdə mötərizə işlənir, Python-da boşluqlar bloku müəyyən edir. Girintini qarışdırmaq ən çox rast gəlinən başlanğıc səhvidir.

Funksiyalar

def salamla(ad):
    return "Salam, " + ad

print(salamla("Aysel"))

Funksiya kodu təkrar istifadə etməyə, proqramı hissələrə bölməyə imkan verir. «Bir funksiya bir iş görsün» prinsipi yaxşı kodun əsasıdır.
